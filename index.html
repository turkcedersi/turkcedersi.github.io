Maarif Etkileşimli Z-Kitap (USB)

Okulunuzda MEB internet engeli veya bağlantı sorunu olsa bile USB belleğe atarak akıllı tahtada sorunsuz kullanabilirsiniz.

Windows (.exe) Pardus ETAP %100 Çevrimdışı 📦 ~910 MB (ZIP)
1
Bilgisayarınıza İndirin

Aşağıdaki butona tıklayarak Maarif_ZKitap_USB.zip dosyasını indirin ve klasöre çıkarın.

2
USB Belleğinize Kopyalayın

Zipten çıkan klasörün içindeki tüm dosyaları USB belleğinize taşıyın.

3
Akıllı Tahtada Tek Tıkla Başlatın

Windows tahtada Maarif_ZKitap.exe'ye, Pardus tahtada Maarif_Pardus.desktop'a çift tıklayın.

Hemen İndir (.ZIP - 910 MB)

Dosya doğrudan GitHub sunucularından en yüksek hızda indirilir.
